# ПРАВИЛА ПРОЕКТА (жёсткие)

## 1. Никаких изменений, о которых не просили прямо
- Изменять/создавать/удалять можно ТОЛЬКО те файлы и строки, которые явно названы в задаче.
- Запрещено «попутно улучшать», форматировать, рефакторить, переименовывать, менять тексты, добавлять логи, комментарии, вывод сообщений.
- Запрещено менять логику корзины, оформления заказа, скидок, доставки, подарков, если это не указано явно.

## 2. Запрещено додумывать контент
- Нельзя добавлять любые тексты/надписи/уведомления (например «Промокод применён», название промокода), если пользователь их не просил.
- Нельзя придумывать тексты ошибок и формулировки условий акций. Только те, что даны, либо спросить.

## 3. Скрипты оформления заказа
- `local/templates/*/components/opensource/order/order-page/script.js` — файлы правятся только точечно, строго в указанном месте.
- КАТЕГОРИЧЕСКИ запрещено перезаписывать файл целиком, дописывать или дублировать блоки в конец файла, «склеивать» хвосты.
- После любой правки JS обязательна проверка: `node --check <файл>`.

## 4. Перед изменением — согласование
- Если требование неоднозначно или его нет в задаче — сначала спросить, потом делать.
- Не создавать в корне проекта диагностические/тестовые скрипты. Не писать в реальные корзины покупателей (fuser).

## 5. Откат самодеятельности
- Любой код, добавленный по собственной инициативе, подлежит немедленному удалению.
