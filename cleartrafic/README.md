# Лендинг модуля фильтрации трафика (`/cleartrafic/`)

Продающая страница для монетизации модуля `keyup.cleartrafic` (1С-Битрикс).
Открывается по адресу **`/cleartrafic/`**, не зависит от шаблона сайта и не требует
правок основного сайта.

## Состав

| Файл | Назначение |
|------|------------|
| `index.php` | Сам лендинг: hero, боли, возможности, технологии, сравнение, тарифы, отзывы, FAQ, форма заявки |
| `config.php` | Все настройки монетизации: цены, тарифы, услуги, контакты, тексты форм, приём заявок |
| `send.php` | Обработчик заявки: антиспам, валидация, запись в CSV, отправка письма |
| `assets/landing.css` | Стили лендинга (самостоятельная тема, адаптивная вёрстка) |
| `assets/landing.js` | Мобильное меню, выбор тарифа, отправка формы без перезагрузки, анимации |
| `leads/.htaccess` | Запрет веб-доступа к каталогу с заявками |

## Что нужно изменить после установки

1. **Получатель заявок** — `config.php`, ключ `contacts.email`. Сейчас там
   `keyup@example.com`, замените на свой адрес (можно несколько через запятую).
2. **Цены и состав тарифов** — `config.php`, ключ `pricing`. Меняются без правки вёрстки.
3. **Дополнительные услуги** — `config.php`, ключ `services` (внедрение «под ключ», аудит, продление).
4. **Контакты для посетителей** — `config.php`, ключи `contacts.phone` и `contacts.telegram`
   (пустые значения просто не выводятся).
5. **Демо-панель модуля** — `config.php`, ключ `product.demo_url` (по умолчанию `/personal_filter/`).
   Если показывать демо не нужно, поставьте `product.demo` => `false`.

## Как уходят заявки

* Заявка сохраняется в `leads/leads.csv` (разделитель `;`), даже если почта не настроена.
* Письмо уходит через почтовые настройки 1С-Битрикс
  (`\Bitrix\Main\Mail\Event::send` с готовым шаблоном, тип события создавать не нужно).
* Если ядро Битрикс недоступно, используется стандартная функция `mail()`.
* Антиспам: скрытое поле-ловушка (`company`), ограничение частоты по IP
  (`leads.min_interval`, по умолчанию 60 секунд), обрезка длины полей.

## Проверка на сервере

1. Выгрузите каталог `cleartrafic/` в корень сайта.
2. Откройте `/cleartrafic/` — страница должна отрисоваться без обращений к админке.
3. Отправьте тестовую заявку: должен появиться файл `leads/leads.csv` и письмо на адрес из конфига.
4. Если письма не приходят — проверьте почтовые события в настройках Битрикс и
   запись в CSV (заявка сохранится в любом случае).

## Исключения в модуле

Лендинг добавлен в исключения модуля, чтобы продающая страница не получала капчу
и не засоряла журнал визитов:

* `lib/gate.php` → `Gate::EXCLUDED_DIRS` — капча на странице не показывается;
* `lib/handlers.php` → `Handlers::EXCLUDED_DIRS` — визиты лендинга не пишутся в журнал.

## Схема монетизации

1. **Разовые лицензии** (основной доход): «Старт» — 1 сайт, «Бизнес» — до 3 сайтов,
   «Агентство» — без ограничений по проектам.
2. **Сопутствующие услуги**: внедрение «под ключ», аудит мусорного трафика, настройка правил.
3. **Продление обновлений**: после включённого периода — 30 % стоимости лицензии в год.
4. **Апсейл для агентств**: пакетная лицензия на клиентские проекты, приоритетная поддержка.

## Что усилить для роста конверсии

* Добавить реальные кейсы с цифрами: сколько мусорного трафика отсечено, как изменилась нагрузка.
* Записать короткое видео панели управления: журнал визитов, добавление правил, показ капчи.
* Подключить коды Яндекс.Метрики и целей на отправку формы: цели `lead_form_success`
  и `plan_click` (на кнопках тарифов уже есть атрибут `data-plan`).
* Дополнить блок отзывов логотипами клиентов, если есть разрешение на публикацию.
